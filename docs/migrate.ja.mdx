---
title: "Waffo Pancake への移行"
description: "pancake-migrate CLI で商品・価格・Webhook・ブランディングを Waffo Pancake に移行"
---

すでに Stripe、Creem、Dodo Payments、Lemon Squeezy を運用していますか？ [`@waffo/pancake-migrate`](https://www.npmjs.com/package/@waffo/pancake-migrate) CLI は、商品・価格・Webhook・ブランディングを Waffo Pancake ストアにコピーします。手入力での再登録は不要です。

<Note>
移行されるのは**カタログと設定**であり、稼働中の課金ではありません。アクティブなサブスクリプション・顧客・支払い方法はそのままの場所に残ります。理由と対処については [移行されないもの](#what-does-not-migrate) を参照してください。
</Note>

<Info>
他のプラットフォームをご利用ですか？現在 **Stripe**、**Creem**、**Dodo Payments**、**Lemon Squeezy** からの移行に対応しており、対応プラットフォームは順次拡大予定です。[お問い合わせ](mailto:support@waffo.ai)いただき、移行元のプラットフォームをお知らせください。優先的に対応します。
</Info>

## 概念のマッピング

何かを実行する前に、既存のセットアップが Waffo Pancake とどう対応するかを確認しておきましょう。このマッピングは CLI が自動で処理します。この表は、何が起きるかを把握するためのものです。

| Stripe / Creem | Waffo Pancake | 備考 |
|---|---|---|
| Product + Price | 1 つの商品（`prices` を含む） | Pancake は価格を商品に統合します。Stripe のマルチ通貨価格は保持されます。Creem は単一通貨です。 |
| Recurring interval | `billingPeriod` | `week`→`weekly`、`month`→`monthly`、3 か月ごと→`quarterly`、`year`→`yearly`。 |
| Webhook endpoint | ストア Webhook | Stripe のエンドポイントは URL + イベントタイプのマッピングとともに移行されます。（Creem の Webhook は CLI では読み取りません。） |
| Account branding | ストアブランディング | Stripe のサポートメール + Web サイトが移行されます。 |
| Tax behavior | `taxCategory` | Creem のカテゴリは自動的にマッピングされます。Stripe では `--tax-category` で 1 つのデフォルトを指定します。 |
| Test / live keys | `test` / `production` | キーのプレフィックスから自動検出されます（`sk_test_`→test、`sk_live_`→production）。 |

## 始める前に

3 つのものが必要です。

1. **Node.js 18+**
2. **Waffo Pancake API キー** — Merchant ID（`MER_...`）と RSA 秘密鍵。[Dashboard → API & Development](https://pancake.waffo.ai/merchant/dashboard/integration) で作成できます。キーの扱い方は [SDK ガイド](/ja/integrate/skill) を参照してください。
3. **移行元プラットフォームのキー** — Stripe Secret Key（`sk_test_...` / `sk_live_...`）または Creem API Key（`creem_test_...` / `creem_...`）。

<Warning>
移行は、キーが示す対象環境（test と live）に商品を**作成**します。何が作成されるかを正確にプレビューするため、必ず最初に `--dry-run` を実行してください。
</Warning>


## スクリプトによる移行

すべてをフラグで渡したい場合（CI や実行の繰り返し向け）は、移行元ごとのサブコマンドを使います。

### Stripe から

```bash
# Full migration (products + webhooks + branding)
npx @waffo/pancake-migrate stripe \
  --stripe-key sk_test_xxx \
  --merchant-id MER_xxx \
  --private-key ./private.pem \
  --store-id STO_xxx \
  --tax-category saas
```

まず `--dry-run` でプレビューします。

```bash
npx @waffo/pancake-migrate stripe \
  --stripe-key sk_test_xxx \
  --merchant-id MER_xxx \
  --private-key ./private.pem \
  --store-id STO_xxx \
  --tax-category saas \
  --dry-run
```

ストアがまだない場合は、`--store-id new` を渡して移行中に作成します。

```bash
npx @waffo/pancake-migrate stripe \
  --stripe-key sk_test_xxx \
  --merchant-id MER_xxx \
  --private-key ./private.pem \
  --store-id new \
  --tax-category saas
```

不要なステップは `--skip-products`、`--skip-webhooks`、`--skip-branding` でスキップします。

```bash
npx @waffo/pancake-migrate stripe ... --skip-webhooks --skip-branding
```

**Stripe フラグ**

| Flag | 説明 |
|---|---|
| `--stripe-key <key>` | Stripe Secret Key（`sk_test_...` または `sk_live_...`） |
| `--merchant-id <id>` | Pancake Merchant ID（`MER_...`） |
| `--private-key <path>` | Pancake API 秘密鍵ファイルへのパス、または生のキー内容 |
| `--store-id <id>` | 移行先 Store ID（`STO_...`）、または `new` で新規作成 |
| `--tax-category <cat>` | デフォルトの税カテゴリ: `saas`、`digital_goods`、`software`、`ebook`、`online_course`、`consulting`、`professional_service` |
| `--dry-run` | 何も作成せずにプレビュー |
| `--yes` | 確認プロンプトをスキップ |
| `--skip-products` | 商品の移行をスキップ |
| `--skip-webhooks` | Webhook の移行をスキップ |
| `--skip-branding` | ブランディングの移行をスキップ |

### Creem から

```bash
npx @waffo/pancake-migrate creem \
  --api-key creem_test_xxx \
  --merchant-id MER_xxx \
  --private-key ./private.pem \
  --store-id STO_xxx
```

まずプレビューします。

```bash
npx @waffo/pancake-migrate creem \
  --api-key creem_test_xxx \
  --merchant-id MER_xxx \
  --private-key ./private.pem \
  --store-id STO_xxx \
  --dry-run
```

**Creem フラグ**

| Flag | 説明 |
|---|---|
| `--api-key <key>` | Creem API Key（`creem_test_...` または `creem_...`） |
| `--merchant-id <id>` | Pancake Merchant ID（`MER_...`） |
| `--private-key <path>` | Pancake API 秘密鍵ファイルへのパス、または生のキー内容 |
| `--store-id <id>` | 移行先 Store ID（`STO_...`）、または `new` で新規作成 |
| `--dry-run` | 何も作成せずにプレビュー |
| `--yes` | 確認プロンプトをスキップ |

## 移行されるもの

### Stripe から

| データ | 移行 |
|---|---|
| Products + Prices | はい — マルチ通貨、画像、説明 |
| Billing periods | はい — `week`→`weekly`、`month`→`monthly`、3 か月ごと→`quarterly`、`year`→`yearly` |
| Webhook endpoints | はい — URL + イベントタイプのマッピング |
| ストアブランディング | はい — サポートメール + Web サイト |
| Environment | 自動検出 — `sk_test_`→test、`sk_live_`→production |

### Creem から

| データ | 移行 |
|---|---|
| Products + Prices | はい — 単一通貨、画像、説明 |
| Billing periods | はい — 毎月→`monthly`、3 か月ごと→`quarterly`、毎年→`yearly` |
| Tax categories | はい — `saas`→`saas`、`digital-goods-service`→`digital_goods`、`ebooks`→`ebook` |

## 移行されないもの {#what-does-not-migrate}

これらは意図的なものです。それぞれの対処方法は次のとおりです。

| 移行されないもの | 理由 | 対処 |
|---|---|---|
| アクティブなサブスクリプション | サブスクリプションは顧客の銀行との稼働中の課金承認であり、決済処理事業者間でコピーできません | 既存の購読者は Waffo Pancake の [チェックアウト](/ja/guides/checkout-session) で再購読します。移行期間中は旧来と新規の決済処理事業者を並行運用してください。 |
| 顧客データ | 初回購入時に自動作成されます | 不要 — 顧客は最初の Pancake 支払い時に作成されます |
| 支払い方法 | PCI 準拠 — カードデータは元の決済処理事業者から外に出ません | 顧客はチェックアウトで支払い情報を再入力します |
| クーポン / 割引 | Lemon Squeezy からのみ移行（下記参照） | 他の移行元のコードはダッシュボードで再作成 |
| チェックアウトのテーマカラー | Stripe は API でこれらを公開していません | [Dashboard → Settings → Checkout](https://pancake.waffo.ai/merchant/dashboard) で設定してください |

## 移行後

<Steps>
  <Step title="カタログを確認">
    **Dashboard → Products** を開き、価格・課金周期・画像が正しく移行されたか確認します。
  </Step>
  <Step title="本番に公開">
    商品はキーが示す環境に作成されます。test に移行した場合は、各商品を [公開](/ja/integrate/skill) して本番稼働させます。
  </Step>
  <Step title="チェックアウトを接続">
    アプリを Waffo Pancake の [チェックアウトセッション](/ja/guides/checkout-session) と [Webhook](/ja/guides/webhooks) に向けます。
  </Step>
  <Step title="並行運用してから切り替え">
    既存の購読者がそれぞれの更新タイミングで移行する間、旧来の決済処理事業者を稼働させたままにします。Pancake チェックアウトが稼働したら、旧来の決済処理事業者での新規登録を停止します。
  </Step>
</Steps>

<Tip>
移行後に統合を構築しますか？ [Waffo Pancake Skill](/ja/integrate/skill) は、チェックアウト・Webhook・サブスクリプション向けの正確な `@waffo/pancake-ts` ワークフローを AI コーディングエージェントに提供します。
</Tip>

## Dodo Payments

Dodo の商品カタログと価格を、既存の Waffo 商品作成処理で移行できます。
`DODO_PAYMENTS_API_KEY` を安全に設定し、まずプレビューします。

```bash
npx @waffo/pancake-migrate dodo --environment test --dry-run
```

書き込む場合は `--merchant-id MER_xxx --private-key ./private.pem --store-id STO_xxx`
を追加し、プレビューを確認して承認します。本番の Dodo 商品を読む場合は
`--environment live` を明示します。キーの接頭辞から環境を推測しません。
プレビューに Waffo の認証情報は不要です。`--store-id new --store-name "My store"`
で承認後にストアを作成できます。商品はテスト版として作成され、本番公開されません。

未アーカイブ商品の全ページと価格の詳細を取得します。固定価格の単発商品と
サブスクリプションに対応し、請求周期は `payment_frequency_*`（週・月・四半期・年）
を使用します。`subscription_period_*` は請求周期として使用しません。
金額は ISO 通貨の最小単位から換算します。元の商品 ID、税と期間の設定を metadata に
保存し、Dodo → Waffo 商品 ID の対応を出力します。

税区分は saas → saas、digital_products → digital_goods、e_book → ebook、
edtech → online_course と明示的に変換します。税込または未指定の税設定では、
移行先の動作を確認して `--acknowledge-tax-semantics` を指定します。
この指定で Waffo の税込設定が変更されることはありません。契約期間は metadata のみです。
未対応の価格・周期・税区分・割引・試用・自由価格・地域別/購買力平価価格・アドオンは
理由付きでスキップされ、終了コードは 1 になります。
顧客、既存契約、支払い方法、Webhook、ブランド、クレジット付与は対象外です。
ウェブサイトのクレジット付与には別途連携が必要です。

## Lemon Squeezy

Lemon Squeezy の商品カタログ、価格、割引コードを移行できます。`LEMONSQUEEZY_API_KEY`
を安全に設定し（テストモードのキーはテストデータ、ライブモードのキーは本番データを読みます）、
まずプレビューします:

```bash
npx @waffo/pancake-migrate lemonsqueezy --dry-run
```

キーが複数のストアにアクセスできる場合は `--ls-store-id <id>` を追加します。移行時は
`--merchant-id MER_xxx --private-key ./private.pem --store-id STO_xxx --acknowledge-tax-semantics`
を追加します。Lemon Squeezy API は価格が税込かどうかを返さないため、移行先の税の扱いを確認したことを
明示します。このフラグは Waffo の税設定を変更しません。商品のみ移行する場合は `--skip-discounts`。
インポートした商品はテストバージョンです。

販売可能なバリアントごとに Waffo 商品を 1 つ作成します（公開済みバリアント、またはバリアントのない
商品の既定バリアント）。名前は `商品名 - バリアント名`（既定バリアントは商品名のみ）。バリアントの現在の
価格をストア通貨・ISO 最小単位で換算します。課金周期: 1 週 → weekly、1 か月 → monthly、
3 か月 → quarterly、12 か月または 1 年 → yearly。税コード: eservice → digital_goods、
ebook → ebook、saas → saas。HTML の説明はプレーンテキストに変換します。

公開済みの割引コードは同じコードの Waffo クーポンになります: 割合または固定額（ストア通貨）、
once / repeating / forever、利用上限、有効期限、対象商品（移行済み商品に対応付け）。クーポンは商品の後に
作成し、読み戻しで検証します。作成先は使用する Pancake API キーの環境です。利用回数はゼロから数え直します。

次は理由付きでスキップされます（終了コード 1）: 下書きの商品・バリアント・割引、任意価格、無料の
リードマグネット、段階 / パッケージ / 従量課金、初期費用、無料トライアル、その他の課金周期、期限切れまたは
開始前の割引、32 文字を超えるコード、未移行バリアントに適用される割引、月額以外のプランに適用される
repeating 割引（Waffo は月ではなく課金周期で数えます）。ライセンスキー、ファイル配布、顧客、既存の
サブスクリプション、支払い方法、Webhook は対象外です。
